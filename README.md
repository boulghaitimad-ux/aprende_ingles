# EnglishPath C1 — versión personalizada

Esta versión está adaptada a una persona con nivel básico que quiere aprender a formar frases y avanzar gradualmente hacia C1, estudiando 45 minutos al día con una mezcla de teoría, juegos y pruebas.

## Qué incluye
- Panel con XP, racha y respuestas correctas guardadas en el navegador.
- Rutina diaria de 45 minutos.
- Constructor guiado de frases para practicar estructuras iniciales.
- Lecciones introductorias sobre orden de palabras, `to be`, presente simple, preguntas y negativas.
- Cuestionario inicial de 12 preguntas con explicación de cada respuesta.
- Ruta de aprendizaje A1–A2 → B1 → B2 → C1.
- Un ejemplo Java independiente en `java/ProgressDemo.java`.

## Cómo ejecutarla
Necesitas Python 3.10 o superior.

1. Abre una terminal en la carpeta del proyecto.
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Inicia el servidor:
   ```bash
   python app.py
   ```
4. Abre `http://127.0.0.1:5000` en el navegador.

Para acceder desde otro dispositivo de tu misma red local, puedes ejecutar el servidor con `host="0.0.0.0"` en `app.py` y entrar usando la IP local del ordenador que lo ejecuta. Hazlo solo en una red de confianza.

## Plan de estudio recomendado
- **Cada día (45 min):** 10 min de teoría, 10 min de vocabulario, 10 min de ejercicios/juegos, 10 min de listening y speaking en voz alta, 5 min de repaso.
- **5 días por semana:** sigue la lección y añade práctica de escucha.
- **1 día por semana:** repaso y mini-test; anota los errores repetidos.
- **1 día flexible:** descanso o contacto ligero con inglés (música, vídeo corto con subtítulos adecuados).

## Ruta orientativa
- **Primeros meses:** consolidar A1 y empezar A2: frases, `to be`, presente simple, preguntas, negativas, artículos, plurales y vocabulario cotidiano.
- **Después:** avanzar a B1 con pasado, futuro, narración, opiniones y textos conectados.
- **Más adelante:** B2 con lectura y escucha más largas, escritura argumentativa y conversación más espontánea.
- **Finalmente:** C1 con textos complejos, matices, collocations, registro, ensayos y simulacros del examen elegido.

El tiempo hasta C1 depende de tu nivel real, constancia, práctica oral y auditiva y exposición al idioma. No hay una duración garantizada. Esta web es un prototipo educativo y no sustituye un curso completo ni la práctica real de listening, speaking, reading y writing.
